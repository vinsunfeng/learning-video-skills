## 环境副作用（hermes 留下的，如实记录）

1. `~/.config/yt-dlp/config` 被写入 `--extractor-args youtube:player_client=android`
   （YouTube 403/SABR 机器人检测，引擎无 cookie 方案，android 客户端仅 360p 可下）。
   这是**全局持久配置**，影响之后所有 yt-dlp 调用；撤销：`rm ~/.config/yt-dlp/config`。
2. 内置 yt-dlp zipapp 的 shebang 依赖 python3.11，hermes 用 /tmp 下的 shim 绕过
   （临时的）；长期修复应把 python3.11 前置进 PATH 或重装 yt-dlp。
